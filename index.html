📱 手机用户三句话搞定
1. 手机必须用 https:// 网址打开才有语音，局域网 http 与手机 localhost 都不放行；
2. 不要在微信 / QQ 内打开——右上角「…」→「在浏览器打开」；
3. iPhone / iPad 请用「⌨️ 文字模式」：iOS 系统不提供网页语音识别，用键盘🎤语音输入最稳。
① 打开方式（九成问题）
只有 https:// 或 http://localhost 才允许调用麦克风。file:// 双击、局域网 http 都直接被拒。电脑双击「本机语音可用-启动.bat」，手机用 https 网址。
② 浏览器权限被拦
· 点地址栏🔒 → 麦克风 → 允许 → 刷新；
· 不弹窗：chrome://settings/content/microphone 删除本站记录再试。
③ 系统权限 / 设备占用
· Windows：设置→隐私→麦克风→允许浏览器；macOS：系统设置→隐私→麦克风→勾选浏览器后重启浏览器；
· 关掉会议 / 录音 / 直播软件（独占麦克风）；外接麦检查插好、选对设备。
④ network 网络错误
云端识别连不上：换 Edge 浏览器；关代理/VPN；切「⌨️ 文字模式」+ 输入法语音（最稳）。

📱别人打不开 / 链接失效 怎么办？▶
❌ 最常见的三种"打不开"原因
1. 是局域网地址（192.168.x.x）：只有同一 WiFi 下的手机才打得开，换网络/发给外面的人必挂。解决：换成 🅲 公网链接。
2. 是 http 而对方是手机：手机浏览器对非 https 页面**禁用麦克风、部分机型甚至拒绝加载**。解决：必须用 https:// 公网地址。
3. 在微信/QQ 里直接点开：微信内置浏览器会拦截很多功能、且不放行麦克风。解决：右上角「…」→「在浏览器打开」。
🔧 排查步骤（按顺序来）
① 先让对方把链接复制到系统浏览器（Safari / Chrome / Edge / 华为浏览器等）打开，不要在微信/QQ 内打开；
② 看地址栏：必须是 https:// 开头，且不是 192.168 / 10. / 172.16 开头的内网 IP；
③ 如果是公网链接但打不开，换网络（Wi-Fi/流量互切）再试，或确认托管平台是否在线；
④ 还是不行 → 直接用 🅰 方式，把 HTML 文件发给对方，100% 打开。
💡 最稳的分享组合
发文件兜底 + 公网链接方便使用：第一次先把 HTML 文件发过去让对方能立刻用，再把公网二维码附带上方便随时扫；对方在微信里打不开，一定提醒"用浏览器打开"。
🔄更新后打开还是旧页面 怎么办？▶
🎯 一句话原因
网址没变、页面却还是旧的，九成是浏览器把上一次的 index.html 缓存住了。文件其实已经更新成功，只是浏览器偷懒没去重新下载。这和"平台没上传成功""网址失效"完全是两回事。
① 先看版本号，确认到底是不是旧版
页面顶部标题右侧有一个版本徽标（V2.0）。你每次更新后，这里应显示新版本号 + 构建日期。如果还是老版本号，说明确实是旧页面被缓存了；如果版本号已经变了，那就不是缓存问题。
② 电脑端：强制刷新（最常用）
· Windows：按 Ctrl + F5 或 Ctrl + Shift + R；
· Mac：按 Cmd + Shift + R；
· 还不行：按 F12 打开开发者工具，在 Network 面板勾选 Disable cache（禁用缓存），再刷新一次；
· 最稳：用无痕 / 隐身窗口（Ctrl+Shift+N）打开一次，能显示新版就说明只是缓存。
③ 手机端：清缓存 / 给网址加个尾巴
· 手机浏览器设置里清除缓存后重新打开；
· 或在网址后面临时加一个随机参数，如 https://xxx.kicp.fun/?v=2，强制绕过缓存（每次把 2 换个数字即可）；
· 微信 / QQ 里打开：右上角「…」→刷新；仍不行 →「…」→「在浏览器打开」，或到 微信「我 → 设置 → 通用 → 存储空间」清理缓存后再扫。
④ 新版页面里点一下就行
打开 ⚙️设置 →「🔄 版本与更新」→ 点「🔄 强制刷新到最新版」，它会自动在网址上加随机参数重载，一步绕过浏览器缓存（二维码地址不变）。
⑤ 如果上面都做了，还是旧页面 → 看这里
A. 换设备验证：用别人的手机 / 电脑打开同一个网址。别人是新的、只有你是旧的 → 100% 是你本地缓存；别人也是旧的 → 是托管平台那边的缓存，或你根本没传上去。
B. 平台 CDN 缓存：花生壳 Drop 上传后有 CDN 缓存，刚传完可能还要等 1~2 分钟才全网生效，稍等再试。
C. 确认"同一个网址"是不是真的同一个：如果你每次上传后拿到的其实是新的网址，那二维码里保存的旧网址自然还是旧页面。请把新网址重新粘贴到设置里的输入框 → 点「生成二维码」，覆盖保存。
D. 想彻底不折腾：登录花生壳控制台，在「静态托管」里给资源设置一个固定的自定义域名前缀，以后固定用这一条网址，不易记混、可长期沿用。
🔒提示“网页不安全”怎么办？▶
🔎 第一步：先分清是哪种“不安全”
① 只是地址栏写着灰字“不安全”，页面能正常打开：说明这个页面走的是 http 未加密连接，不是中毒、也不是网站被黑。浏览器的意思是“这户没装防盗门”。对即兴说的影响只有一个：手机浏览器会禁用麦克风。解决：改用 https:// 开头的地址（Drop 上传得到的 https://xxx.kicp.fun 就是 https，扫码打开不会有这个提示）。
② 整页红色拦截：“您的连接不是私密连接 / 此网站无法提供安全连接”：这是证书问题（证书过期、域名不匹配，或刚申请的免费域名证书还没就绪）。处理：点「高级」→「继续前往（不安全）」即可临时进入（本页面是你自己的内容，可放心）；或换个浏览器、换网络过一会儿再开。若是刚部署的地址，等几分钟再试往往就好了。
③ 在微信 / QQ 里提示“无法确认该网页的安全性，请谨慎访问”：这是微信内置浏览器的风控拦截，不是你的页面有问题。处理：页面上点「继续访问」，或右上角「…」→「在浏览器打开」，正文就会正常显示、麦克风也才放行。
🧭 第二步：4 步判断是“网站问题”还是“你本地问题”
① 换网络对比：同一个网址，用手机流量开一次、家里宽带上一次。两个都提示→ 是网站/托管平台那边的问题；只在某一个网络提示→ 是你本地网络或设备的问题。
② 用无痕 / 隐身窗口再开一次：如果变正常了，多半是浏览器扩展在捣乱（广告拦截、VPN、脚本类插件），逐个禁用即定位。
③ 核对日期时间：手机/电脑的时间不准，会让浏览器误判证书“过期/未生效”。把「自动设置日期和时间」打开。
④ 关掉 VPN / 代理 / 杀毒软件的“HTTPS 扫描”，再刷新一次。
✅ 即兴说场景 · 最省心的做法
1. 分享给别人一律用 Drop 上传得到的 https 公网地址（https://xxx.kicp.fun），既没有“不安全”提示、麦克风也能用；
2. 不要把 http://192.168.x.x 这种局域网地址当分享链接发出去；
3. 在微信里打开时，先「…」→「在浏览器打开」，再授权麦克风；
4. 实在不行就用最稳的兜底：把 HTML 文件直接发给对方，对方用自己的浏览器打开，完全不受网络和证书影响。
⚠️ 小提醒
浏览器的“不安全”提示说的是传输有没有加密，和网页里有没有病毒是两回事；但如果不是你自己发的页面，看到警告又要求输入账号密码、验证码，请直接关掉。即兴说是纯本地单文件、不收集任何数据，你自己的地址可以放心继续访问。

⚔️辩论对抗怎么玩（AI 对辩）？▶
赛制：参考新国辩标准赛制简化版——
· 开篇立论：正方一辩立论 3 分钟 → 反方一辩立论 3 分钟；
· 攻辩环节：正方二辩攻辩 2 分钟 → 反方二辩攻辩 2 分钟 → 正方三辩攻辩 2 分钟 → 反方三辩攻辩 2 分钟；
· 自由辩论：双方各 4 分钟，交替发言；
· 总结陈词：反方四辩总结 3 分钟 → 正方四辩总结 3 分钟。
玩法：抽辩题后点「⚔️ 开始辩论」，选择你要站的一方（正方/反方），另一方由 AI 扮演，系统按轮次计时、轮到 AI 时自动生成该方立论/反驳/总结发言，你对着麦克风或文字输入作答即可，轮次结束 AI 会从立论、攻辩、自由辩、结辩四维复盘。
